Shadowsocks 高级教程

proxyshadowsocks

1. HTTP代理

在网上看到建立shadowsocks之后会自动建立一个http的代理，使用8123端口，知道这一点就可以使用http代理而不仅只是socks5了

2. Shadowsocks服务端配置

曾在DigitalOcean上自建了一个Shadowsocks服务端，虽然后来被封了，但幸而在电脑上记录下一下重点，Shadowsocks服务端的配置文件为:

#ipv4
{
    "server":"0.0.0.0",
    "server_port":443,      #经尝试，443端口比其他端口要快一点
    "local_port":1080,
    "password":"******",
    "timeout":600,
    "method":"aes-256-cfb"
}
#ipv6
{
    "server":"::",
    "server_port":443,
    "local_port":1080,
    "password":"******",
    "timeout":600,
    "method":"aes-256-cfb"
}

<!--more-->

3. Shadowsocks服务端的安装

源码在此处 先安装pip再安装SS：

apt-get install python-pip
pip install shadowsocks

如果默认Python版本不对则需要先安装Python，不赘述。

4. Shadowsocks服务端的启动与关闭

ssserver -c config -d start
ssserver -c config -d stop

其中config即前面配好的配置文件

5. 检查日志

sudo less /var/log/shadowsocks.log

日语学习第九讲

japanese

前言

距离上一次写日语学习系列已经快两年了，这两年间日语水平并没有什么长进，甚至还在倒退，但却总有一个心结，想要将这个系列完成。 好了，话不多说，其实之前的文章内容已经基本涵盖了日语基础语法的各个方面，而这篇文章打算说说日语中一个句子的分析和改造顺序，也算是对前面内容的一个总结。 日语的变形，主要体现在用言(动词/形容词/形容动词)、助动词上，这其中又属动词最为复杂。

<!--more-->

1. 分析顺序

1.1 说明

给出一句日语，我们如何分析它用了哪些语法结构呢？

  1. 如果这个句子是由多个句子复合而成的句子，首先将句子拆分，按照2至6的步骤分析单个从句，分析完从句后，将从句看作整个句子的一个成分，用符号代替，再按照2至6的步骤分析主句。需要注意的是，语气和敬意通常都是在主句中表达的，所以从句也不太可能需要分析2和3，还有一点是，如果从句本身是经过活用变形的(如假定型的活用)，先将这种变形去除.
  2. 在讲解语气的文章中提到了语气的种种分类，但实际中，语气大多还是通过特定词语、附加助词和语调的变化来表达的，因此即使一个句子用到了特定的语气，也不会在句子形式上有大的变化，最常见的也只是添加了句尾助词，可以先将助词去掉，简化句子，再做分析.
  3. 之后我们需要区分的是这句话是否是敬语形式，敬语的形式很容易看出来，因此如果用了敬语，那么先将这个句子还原为普通形式.
  4. 在还原为普通形式后，可以继续分析该句是否用到了特殊的"体"，如「ている」这种表示持续体的特殊形式，如果有的话，将特殊的"体"去掉，再次简化句子.
  5. 已经去掉了"体"的变形，之后就是分析简化的句子中，是否还用到了特殊的语态，如果用到了语态，就将其变化形式还原.
  6. 经过以上还原后，剩下的句子就只剩下时和极性的变形了，而时和极性我们通常都是放在一起记忆的，所以也可以一次性将其还原为基本型. 如果硬要分一个顺序，应该是先还原时，再还原极性.

1.2 示例

写了这么多，给出几个句子我们分析一下。我们先用大家熟悉的动漫和日剧台词来做开胃菜。

  1. 《半泽直树》经典台词：「やられたらやり返す、倍返しだ！」

    • 这个句子首先是一个复合句，那么先分析从句：「やられたら」
    • 由于用了假定型「たら」，将其还原为「やられる」
    • 可以看出现在这种形式，是用了被动态的，将其还原为最基础的动词「やる」（做/干）
    • 这样从句就分析完毕了，接着分析主句：「やり返す、倍返しだ！」
    • 「やり返す」是复合动词，由「やる」（做）+「返す」（返回/回应）组成，意思是“反击/做回去”。
    • 「倍返しだ！」是名词「倍返し」加上断定助动词「だ」。
    • 整体语法分析下来，这句话就是：“如果（我）被搞了，（我）就要反击，加倍奉还！”

  2. 《海贼王》路飞台词：「海賊王に、俺はなる！」

    • 这句话其实运用了语调语气的强调和语序倒装。
    • 把它还原成正常的普通形式应该是：「俺は海賊王になる！」（我要成为海贼王！）
    • 倒装的目的是为了把核心目标「海賊王に」放在句首进行强烈强调，这在实际口语和动漫台词中非常常见。

  3. 原点分析：人は褒められれば嬉しいものなのです 这个句子首先是一个复合句，那么先分析从句: 「人は褒められれば」 由于用了假定型，将其还原为 「人は褒められる」 可以看出这种形式用了被动态，将其还原为「人は褒める」 这样从句就分析完毕了，接着分析主句「嬉しいものなのです」 可以看出主句只用了敬语的一种比较特殊的形式「な+のです」，直接简化为「嬉しいものだ」

  4. 进阶分析：勉強をさせられている生徒に教えることは、ザルに水を注ぎ続けるようなもの！[1] 这个句子也是一个复句，可以当作包孕句处理。 首先分析前半句，「勉強をさせられている生徒に教えることは」， 去掉从句的连接词，句子可以简化为「勉強をさせられている生徒に教える」. 而这个从句中还有一个定语从句「勉強をさせられている」，这个句子用了「ている」的"体"表示一种持续的状态，简化后变为「勉強をさせられる」 而「勉強をさせられる」又是典型的被役态，还原成最基本的形式就是「勉強をする」 这样就可以理解前半句的意思了: "教一直被逼着学习的学生这种事". 再分析后半句，「ザルに水を注ぎ続けるようなもの」，后半句没有用到特殊的变形，只是用了「ようなもの」这种惯用语，表示"像竹篮打水一样"

2. 改造顺序

2.1 说明

给定一个句子，如何去分析已经了解了。那在实际语境下，假设我们从最基础的形式出发，需要以什么样的顺序来对这个句子进行变形，从而达到我们想要表达的意思呢？ 其实就是把分析的过程倒过来就行.

  1. 先明确句子的极性和时
  2. 再思考这句话的主体、情态，是否需要用到特殊的语态
  3. 考虑语境下是否有特殊的时间状态，即是否要用到体的变形
  4. 是否需要用敬体，如果需要用敬体的时和体替换原有的时和体
  5. 如果需要特殊语气，就通过助词和语调调整
  6. 单句无法表达时，通过组合句子来表达

2.2 示例

平时在看剧时，多分析看到的复杂句是怎么构成的，如果是自己来表达同样的意思，会怎么表达。我们用一个具体的场景来演练一下这套“改造顺序”。

场景与情绪：今天下暴雨，我完全不想去学校，我想乞求老师让我休息。 中文：“因为今天下雨，所以我不想去学校。能请您（老师）让我休息吗？”

改造步骤拆解：

  1. 基础词汇提取：今日(きょう)、雨(あめ)、降る(ふる)、学校(がっこう)、行く(いく)、休む(やすむ)。
  2. 极性与时态：
    • 不去学校（极性：否定）：行く -> 行かない。
    • 今天下雨（时态：现在/进行）：降る -> 降っている。
  3. 主体、情态与特殊语态：
    • 我不想去（情态：个人意愿）：行かない -> 行きたくない。
    • 老师让我休息（语态：使役，表示允许/使得）：休む -> 休ませる。
  4. 语境与体：
    • 原因“因为下雨”：降っている -> 降っているので（接续助词）。
  5. 敬体制替换：
    • 因为是对老师说话，需要用敬语（丁宁体）： 行きたくない -> 行きたくありません（或者 行きたくないです）。
    • 请求对方做某事，并且是谦卑的恳求，使用授受表达与可能的敬语组合： 让他人允许自己做某事（使役+授受请求）：休ませる -> 休ませていただけませんか（能请您让我休息吗？最尊重的请求句式之一）。
  6. 最终组装： 「今日は雨が降っているので、学校に行きたくありません。休ませていただけませんか。」

你看，哪怕是一个看起来有些复杂的请求句，通过逐步拆解与叠加变形，也能轻松地组合出来。这就像搭乐高积木一样，只要清楚每一块积木的作用，就能搭出任何想要的模型。

总结

分析的目的，和语文、英语的拆解句子结构一样，就是熟悉语法。 改造的目的，和语文、英语中的造句一样，就是正确熟练地表达。 等到不拘于此，不再需要思考如何去理解、如何去说，直接就能阅读和表达时，也就是真正掌握日语语法的时候. 本篇文章主要总结了日语中句子的分析和改造顺序，下一篇将介绍日语中的一些实用表达。

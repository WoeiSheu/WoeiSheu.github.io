Windows 琐记三

windowscmdcharset

1. cmd下设置字符集

chcp 437     // set english       environment
chcp 932     // set japanese      environment
chcp 936     // set chinese(sim)  environment
chcp 949     // set chinese(tra)  environment
chcp 950     // set korean        environment
chcp 65001   // set utf-8         environment

改成437后可以解决一些乱码问题, 奇怪的是明明装的是英文系统竟然默认是936
